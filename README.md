# SQL & Python Daily Practice

A running log of small SQL and Python lessons and exercises - queries solved, scripts written, and concepts re-explained in my own words. This isn't a polished portfolio repo; it's where I rebuild and maintain fluency through consistent, low-pressure practice.

## Why this exists

Portfolio projects show what I've built. This repo shows how I think, day to day - the actual problem-solving process, not just a finished result.

## Structure

```
sql-python-daily-practice/
├── sql/
│   └── (files, e.g. 'Lesson-01-SQL-Fundamentals)
├── python/
│   └── (files)
└── notes/
    └── concepts-explained.md   — short write-ups of concepts in my own words
```
